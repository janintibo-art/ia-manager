# IA Manager v143 — Heretic Research + comparateur chirurgie

## Recherche Heretic
Ajoute dans l'onglet Heretic :
- installation des dépendances optionnelles `research` ;
- impression de la géométrie résiduelle ;
- projection PaCMAP des représentations internes ;
- génération des images/animations Heretic ;
- dossier de résultats séparé ;
- historique des analyses ;
- nombre d'essais configurable ;
- journal temps réel ;
- arrêt propre ;
- réservation des ressources locales.

Les projections PaCMAP peuvent être coûteuses en CPU et prendre longtemps.

## Comparateur Original / Obliteratus / Heretic
- trois sélecteurs Ollama ;
- préremplissage possible depuis le registre Obliteratus ;
- envoi des trois variantes vers le Benchmark v140 ;
- préparation directe des comparaisons qualitatives v141 :
  - Original ↔ Obliteratus ;
  - Original ↔ Heretic ;
  - Obliteratus ↔ Heretic.

IA Manager ne donne pas de verdict global sur les variantes :
il prépare les mêmes mesures et critères pour faciliter une comparaison reproductible.
