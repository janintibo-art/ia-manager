# IA Manager v41 — favoris multi-sources

La recherche permet maintenant de mémoriser les modèles intéressants.

## Favoris

Dans la fiche d'un résultat, **Ajouter aux favoris** enregistre la source, l'identifiant et le nom du modèle. Le marqueur `★` apparaît ensuite dans les résultats Hugging Face, GitHub, ModelScope ou Civitai.

Les favoris sont conservés dans les réglages locaux, limités aux 200 derniers et ne contiennent aucun jeton ni secret. Le même modèle peut être suivi séparément sur deux sources différentes.
