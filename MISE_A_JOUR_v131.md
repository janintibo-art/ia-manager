# IA Manager v131 — français dans Obliteratus

- Français activé par défaut dans l’atelier Obliteratus intégré.
- Sélecteur Français / English.
- Choix mémorisé dans les réglages IA Manager.
- Francisation des boutons principaux :
  - lancement / arrêt ;
  - préparation de la source Hugging Face ;
  - comparatif Avant / Après ;
  - gestion des versions.
- Traduction à l’affichage des principaux messages techniques du moteur dans le journal :
  - chargement ;
  - analyse ;
  - extraction des directions ;
  - raffinement ;
  - vérification ;
  - sauvegarde ;
  - téléchargement ;
  - mémoire GPU ;
  - perplexité ;
  - cohérence ;
  - avertissements et erreurs.

Remarque : l’ancienne interface Gradio officielle d’Obliteratus reste une interface tierce.
Le mode intégré IA Manager devient l’interface française recommandée.
