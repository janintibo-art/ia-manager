# IA Manager v158 — Bibliothèque IA intelligente

Nouvel onglet `📚 Bibliothèque IA`.

Fonctions :
- liste du catalogue IA Manager + modèles Ollama installés hors catalogue ;
- recherche texte ;
- filtres par spécialité, installation et compatibilité ;
- taille estimée ;
- compatibilité matérielle estimée ;
- mémoire estimée ;
- quantification si elle est explicitement identifiable dans le tag ;
- sinon `Gérée par Ollama` ;
- licence affichée `Non renseignée` quand elle n'est pas connue localement ;
- source du modèle ;
- usage conseillé.

Actions :
- Voir la fiche détaillée dans `Modèles` ;
- Ouvrir un modèle installé directement dans `Chat` ;
- Pré-sélectionner le modèle dans `Benchmark IA` ;
- Ouvrir le dossier Ollama ;
- Ouvrir la fiche de téléchargement pour un modèle non installé.

La v158 évite d'inventer les licences ou quantifications inconnues.
