# IA Manager v152 — Progression visuelle

Ajoute de petites barres de progression cohérentes aux opérations longues.

## Pourcentage réel
La Recherche conserve la progression 0–100 % lorsqu’un téléchargement
Ollama / GitHub / Civitai remonte sa taille.

## Barre animée
Quand l’outil externe ne fournit pas de pourcentage fiable, IA Manager
affiche une barre animée plutôt qu’un faux pourcentage.

Zones couvertes :
- recherche et chargement des fiches ;
- téléchargement de modèles ;
- installation automatique de Python ;
- Outils locaux / pip / moteurs créatifs ;
- création d’images ;
- entraînement, fusion et import Ollama ;
- Heretic ;
- Abliteration Lab ;
- ErisForge ;
- MergeKit.

Les barres restent petites et disparaissent automatiquement à la fin.
