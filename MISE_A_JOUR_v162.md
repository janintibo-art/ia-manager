# IA Manager v162 — Profils matériels

Nouvel onglet `🖥️ Profils matériels`.

Fonctions :
- enregistrement de plusieurs configurations ;
- détection du PC actuel ;
- duplication pour simuler une future configuration ;
- édition CPU, GPU, constructeur, VRAM et RAM ;
- sélection d'un profil actif ;
- distinction entre matériel détecté et profil de recommandation ;
- suppression sécurisée en conservant toujours au moins un profil.

Le profil actif alimente les recommandations de :
- Catalogue Modèles ;
- Bibliothèque IA ;
- Entraînement / QLoRA ;
- résolution de départ dans Création d'images ;
- conseil vidéo dans Audio · Vidéo · 3D.

L'onglet Analyse reste basé sur le matériel réellement détecté et n'est jamais falsifié par un profil manuel.

Résumé par profil :
- modèles texte conseillés ;
- résolution image de départ ;
- prudence vidéo ;
- niveau d'entraînement conseillé.
