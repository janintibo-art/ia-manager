# IA Manager v175 — ComfyUI en 1 clic

La v175 applique au studio Image le même principe que la v174 pour Ollama.

## Nouveau panneau ComfyUI

Dans **Création d'images**, IA Manager affiche maintenant un état clair :

- ComfyUI absent ;
- ComfyUI installé mais arrêté ;
- ComfyUI lancé ;
- modèle sélectionné présent ou manquant.

## Actions

- **Installer / réparer ComfyUI** :
  ouvre directement Outils locaux avec ComfyUI déjà sélectionné.
- **Démarrer ComfyUI** :
  utilise le moteur ComfyUI géré par IA Manager.
- **Vérifier** :
  contrôle le serveur local et actualise les checkpoints.
- **Ouvrir ComfyUI** :
  ouvre l'interface locale lorsque le moteur fonctionne.

## Modèles déjà téléchargeables

La v175 conserve les téléchargements existants :
- SDXL 1.0 ;
- SDXL Turbo ;
- Animagine XL 4.0 ;
- FLUX.1 Schnell FP8.

Le bouton existant **Télécharger et installer ce modèle** reste le point unique pour les checkpoints.

## Objectif

Le parcours devient :
1. installer ComfyUI ;
2. démarrer ComfyUI ;
3. télécharger le modèle ;
4. vérifier ;
5. générer.

## Suite

La prochaine étape logique est d'appliquer le même cycle aux modèles **Audio / Musique**.
