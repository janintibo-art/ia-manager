# IA Manager v146 — Tableau de bord Chirurgie IA

Nouvel onglet `🧠 Chirurgie IA`.

## Regroupe
- Obliteratus
- Heretic
- Abliteration Lab
- ErisForge

## Fonctions
- un champ de modèle source commun ;
- état d’installation de chaque moteur ;
- résumé de l’approche de chaque outil ;
- assistant de choix selon l’objectif :
  - flux simple ;
  - optimisation automatique ;
  - contrôle géométrique ;
  - transformation comportementale personnalisée ;
- envoi direct du modèle source vers l’outil choisi ;
- accès immédiat au Benchmark ;
- accès à Famille IA ;
- accès au comparateur Original / Obliteratus / Heretic.

Le tableau de bord n’exécute aucune chirurgie lui-même.
Il sert uniquement de poste de commande et de navigation.
