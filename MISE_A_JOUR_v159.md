# IA Manager v159 — Assistant « Que voulez-vous faire ? »

Nouvel onglet `✨ Que voulez-vous faire ?`.

Objectifs disponibles :
- discuter avec une IA ;
- créer une image ;
- créer musique / son ;
- créer une vidéo ;
- créer un objet 3D ;
- entraîner une IA ;
- fusionner des IA ;
- modifier un modèle avec Chirurgie IA ;
- trouver / télécharger un modèle ;
- gérer les modèles ;
- comparer des IA ;
- diagnostiquer / réparer.

Fonctionnement :
- l'utilisateur choisit un objectif, pas un outil technique ;
- IA Manager ouvre le bon onglet ;
- pour Audio/Vidéo/3D, la bonne catégorie est présélectionnée ;
- pour Benchmark, Bibliothèque et Centre de santé, les données sont actualisées ;
- aucun traitement lourd n'est lancé automatiquement sans action explicite ;
- un filtre permet de retrouver rapidement un objectif.

L'assistant est ajouté en première position dans la section ACCUEIL.
