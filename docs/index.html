04 / PREMIERS PAS

Quelques minutes pour commencer.

01

Préparez le PC

Téléchargez l’EXE et lancez IA Manager. Choisissez votre dossier de stockage dans Connexions si besoin. Installez Ollama, puis choisissez un modèle adapté à votre machine. Configurez les moteurs dans Connexions.

02

Lancez une conversation

Dans Chat, sélectionnez un modèle et envoyez un message. Ajoutez vos fichiers et créez un projet pour retrouver votre travail. L’onglet Tuto vous accompagne.

03

Connectez Android

Sur le PC, ouvrez Téléphone et démarrez le serveur. Installez l’APK, puis saisissez l’adresse et le code affichés sur le PC. Autorisez le serveur sur votre réseau privé si Windows le demande.

LES QUESTIONS UTILES

Avant de vous lancer.

Est-ce que tout fonctionne sans Internet ?

Les modèles locaux déjà téléchargés peuvent fonctionner hors ligne. Les téléchargements, la recherche web et les fournisseurs API distants ont besoin d’Internet. Le compagnon Android a besoin d’une connexion réseau au PC.

Peut-on enregistrer les modèles sur D: ?

Oui : dans Connexions sur Windows, choisissez un dossier sur D: et utilisez l’option de copie. L’application règle le dossier des modèles Ollama et conserve les originaux sur C: ; certains fichiers propres à Obliteratus sont gérés séparément.

Le téléphone fait-il tourner les modèles ?

Non. Le calcul a lieu sur le PC. Le compagnon Android sert à discuter avec les modèles accessibles sur cet ordinateur.

Mes conversations restent-elles locales ?

Avec un moteur local et les fonctions distantes désactivées, les échanges sont traités sur votre ordinateur. Une API distante ou une recherche Internet contacte le service choisi. Le serveur mobile actuel utilise HTTP : réservez-le à un réseau local de confiance, sans ouverture de port Internet.

Pourquoi installer l’APK manuellement ?

L’application compagnon est distribuée ici sous forme d’APK de test. Android peut demander d’autoriser l’installation depuis votre navigateur. La signature de test peut changer si le cache de compilation est perdu ; une réinstallation peut alors être nécessaire et effacer l’historique local du téléphone.

Windows affiche un avertissement au lancement ?

L’EXE n’est pas signé avec un certificat d’éditeur commercial. Vérifiez que le téléchargement provient bien de ce dépôt et consultez les détails de votre protection Windows avant de décider de l’exécuter.

Comment signaler un problème ou proposer une idée ?

Ouvrez un ticket dans les Issues GitHub, en indiquant votre système, la version et les étapes pour reproduire le problème. Retirez les clés API et les informations personnelles des captures.
