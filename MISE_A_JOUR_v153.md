# IA Manager v153 — ComfyUI Doctor

Nouveau bloc ComfyUI Doctor dans Outils locaux.

Fonctions :
- diagnostic de l’installation ComfyUI ;
- vérification du Python isolé, Git et du Manager officiel ;
- détection de ByteDance SeedAudio dans le code ComfyUI ;
- option `Activer les nœuds API partenaires` ;
- option `Activer ComfyUI Manager` ;
- mise à jour/réparation ComfyUI en un clic ;
- installation/réparation des dépendances du Manager ;
- liste intégrée `LOCAL / API` pour distinguer les outils sans crédit des Partner Nodes.

Le mode local/gratuit reste le comportement par défaut :
IA Manager continue de désactiver les API partenaires tant que l’utilisateur ne les active pas explicitement.
