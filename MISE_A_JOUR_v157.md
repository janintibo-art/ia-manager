# IA Manager v157 — Centre de téléchargements

Nouvel onglet `⬇ Téléchargements`.

Fonctions :
- suivi centralisé des téléchargements Ollama, GitHub GGUF et Civitai lancés depuis IA Manager ;
- progression réelle quand les octets sont disponibles ;
- taille téléchargée / taille totale ;
- vitesse instantanée lissée ;
- estimation du temps restant ;
- état : en cours, terminé, échec, annulé, interrompu ;
- annulation quand le worker sait s'arrêter ;
- relance automatique pour les téléchargements Ollama ;
- ouverture du dossier cible quand connu ;
- historique persistant des 200 derniers transferts ;
- détection des téléchargements interrompus au redémarrage ;
- vue du cache temporaire et nettoyage en un clic.

Le centre reprend aussi les téléchargements lancés depuis l'onglet Analyse.
