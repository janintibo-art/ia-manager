# IA Manager v49 — gestion des favoris

Les favoris disposent maintenant d'une suppression globale contrôlée.

## Effacement

Le bouton **Effacer favoris** indique le nombre d'entrées et demande une confirmation avant de supprimer la liste. Les fichiers téléchargés, les modèles Ollama et les caches restent totalement inchangés.

L'export, l'import, le filtre et la suppression individuelle restent disponibles.

## Vérification

La compilation syntaxique et les 44 tests ciblés passent localement. GitHub Actions doit confirmer la compilation Windows et l'interface complète.
