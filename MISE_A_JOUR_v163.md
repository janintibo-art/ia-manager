# IA Manager v163 — Historique universel

Nouvel onglet `🕘 Historique`.

Fonctions :
- timeline centrale persistante ;
- filtres par type ;
- recherche texte ;
- ouverture du dossier de résultat ;
- retrait d'une ligne sans supprimer le résultat original ;
- effacement de la timeline sans supprimer benchmarks, modèles ou expériences ;
- actualisation automatique toutes les 15 secondes.

Import automatique des historiques existants :
- téléchargements ;
- benchmarks quantitatifs ;
- comparaisons qualitatives avant/après ;
- entraînements / fusions ;
- journal d'erreurs synthétique.

Nouveaux événements suivis :
- téléchargements v157 terminés / échoués / interrompus ;
- benchmarks ;
- entraînement / fusion / import Ollama ;
- installations, diagnostics et sessions d'outils locaux ;
- migrations de stockage.

La timeline conserve jusqu'à 1000 événements.
