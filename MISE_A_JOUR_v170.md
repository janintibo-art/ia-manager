# IA Manager v170 — centre d'installation

Cette version poursuit la correction « tout téléchargeable depuis l'application ».

- nouvel écran **Installations** avec vérification globale ;
- installation directe via WinGet pour **Ollama, Git, GitHub CLI, Node.js LTS, Python 3.11 et Blender** ;
- installation directe de **pterm** via npm ;
- détection de ComfyUI installé par IA Manager et raccourci vers son installation ;
- état clair pour Pinokio quand l'installation reste à faire via la distribution officielle ;
- **Animagine XL 4.0** devient téléchargeable directement dans `ComfyUI/models/checkpoints`, comme SDXL et SDXL Turbo ;
- liens officiels de secours conservés si WinGet n'est pas disponible.

L'installation des modèles complexes FLUX / vidéo reste volontairement guidée car ils nécessitent plusieurs poids et un workflow spécifique, pas un seul checkpoint.
