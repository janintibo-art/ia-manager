# IA Manager v149 — Check-up visuel global et navigation dynamique

## Problème corrigé
La navigation historique utilisait des indices fixes correspondant aux anciens
onglets. Les nombreuses extensions ajoutées depuis pouvaient déplacer les indices.

La v149 reconstruit la navigation à partir des widgets réellement présents.

## Ergonomie
- nouveau champ `Filtrer les écrans…` dans la navigation ;
- recherche par nom ou description ;
- sections sans résultat masquées pendant la recherche ;
- rail légèrement élargi ;
- bandeau supérieur limité en hauteur ;
- synchronisation automatique du titre et du sous-titre ;
- vérification que chaque onglet réel possède une entrée de navigation.

Aucune fonction métier n’est supprimée.
