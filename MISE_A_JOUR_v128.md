# IA Manager v128 — comparatif Avant / Après Obliteratus

- Nouveau panneau de comparaison directement dans l’onglet Obliteratus.
- Sélection d’un modèle original et d’un modèle modifié importé dans Ollama.
- Un même prompt est envoyé aux deux modèles.
- Réponses affichées côte à côte.
- Historique local des comparaisons.
- Réouverture d’une comparaison passée en un clic.
- Boutons pour ouvrir soit le modèle original, soit la version Obliteratus dans le Chat.
- Après conversion/import d’un modèle Obliteratus, la liste des modèles Ollama est rafraîchie automatiquement.
- Préselection automatique du modèle d’origine transmis depuis le catalogue et du dernier modèle Obliteratus exporté.
