# IA Manager v42 — filtre favoris

La recherche multi-sources dispose maintenant d'un filtre **Favoris uniquement**.

## Utilisation

Activez la case à côté de la source pour ne garder que les modèles déjà marqués avec `★`. Le filtre respecte la source sélectionnée : un dépôt GitHub et un modèle Civitai portant un nom similaire restent distincts.

Le filtre peut être utilisé avec une recherche vide pour retrouver rapidement votre sélection, ou avec un mot-clé pour réduire encore les résultats.

La compilation syntaxique et les 37 tests ciblés passent localement. GitHub Actions doit confirmer la compilation Windows et l'interface complète.
