# IA Manager v118 — Démarrage guidé Audio / Vidéo / 3D

La page Audio · Vidéo · 3D est simplifiée.

## Nouveau bloc “Démarrage rapide”
Pour chaque modèle :
- affiche clairement le moteur à installer ;
- indique s’il est déjà installé ;
- donne les étapes dans l’ordre ;
- bouton 1 : installer le moteur recommandé ;
- bouton 2 : aller au démarrage ;
- bouton 3 : ouvrir l’interface.

## Passage automatique vers Outils locaux
Le moteur correspondant est présélectionné :
- Hunyuan3D 2 → Hunyuan3D 2
- TripoSR → TripoSR
- MusicGen / AudioGen → AudioCraft
- Wan / LTX / CogVideoX → ComfyUI

## Outils locaux simplifié
Les boutons sont maintenant numérotés :
1. Installer / reprendre
2. Démarrer
3. Ouvrir l’interface

Le bouton Démarrer reste désactivé tant que l’installation gérée n’est pas terminée.
