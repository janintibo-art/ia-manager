# IA Manager v160 — Recettes / workflows prêts à l'emploi

Nouvel onglet `📖 Recettes / workflows`.

Recettes incluses :
- Image locale SDXL / ComfyUI
- Musique locale MusicGen Small
- Vidéo locale Wan 2.1 dans ComfyUI
- 3D rapide TripoSR
- 3D détaillée Hunyuan3D 2
- Entraînement LoRA / QLoRA
- Fusion MergeKit
- Chirurgie IA

Chaque recette :
- indique le moteur recommandé ;
- vérifie si le moteur semble installé ;
- présente les étapes numérotées ;
- propose un bouton Ouvrir pour chaque étape ;
- prépare automatiquement la bonne catégorie ou le bon moteur ;
- ouvre d'abord Outils locaux si un moteur requis n'est pas prêt ;
- n'exécute aucune opération lourde sans validation explicite.

L'onglet est ajouté en tête de la section CRÉER.
