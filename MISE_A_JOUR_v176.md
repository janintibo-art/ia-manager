# IA Manager v176 — AudioCraft, MusicGen et AudioGen en parcours unifié

La v176 applique le principe « tout depuis IA Manager » à la catégorie **Musique et sons**.

## Modèles concernés

- MusicGen Small
- MusicGen Melody
- AudioGen Medium

## Nouveau panneau AudioCraft

Dans **Audio · Vidéo · 3D**, lorsque l'un de ces modèles est sélectionné, un panneau dédié affiche l'état réel :

- moteur AudioCraft absent ;
- moteur installé ;
- poids du modèle à préparer ;
- poids prêts ;
- interface locale prête à ouvrir.

## Actions

- **Installer / réparer AudioCraft**
  - ouvre Outils locaux avec AudioCraft déjà sélectionné ;
- **Préparer les poids**
  - réutilise le téléchargement v172 via Hugging Face ;
- **Démarrer AudioCraft**
  - lance le moteur local géré par IA Manager ;
- **Vérifier**
  - relit l'état moteur + poids ;
- **Ouvrir l'interface**
  - ouvre l'interface locale synchronisée par IA Manager.

## Continuité

La v176 ne remplace pas le système v172 : elle le rend plus simple à utiliser en regroupant les actions au même endroit.

## Suite

La prochaine étape logique est la **v177 Vidéo**, pour Wan 2.1 / LTX-Video via ComfyUI.
