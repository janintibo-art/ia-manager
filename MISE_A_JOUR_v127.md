# IA Manager v127 — sources Hugging Face pour Obliteratus

Cette mise à jour complète le mode Obliteratus intégré de la v126.

- Bouton « Préparer / télécharger la source HF ».
- Téléchargement du checkpoint Hugging Face complet directement depuis IA Manager.
- Stockage dans le dossier de modèles configuré par l’utilisateur, sous `HuggingFace/`.
- Réutilisation automatique d’un checkpoint déjà présent.
- Bascule automatique de la référence distante vers le chemin local après téléchargement.
- Affichage de l’état, du chemin et de la taille de la source locale.
- Bouton pour ouvrir directement le dossier du checkpoint.
- Journal de téléchargement visible dans l’onglet Obliteratus.
- Arrêt propre et réservation des ressources locales.
- Télémétrie Hugging Face désactivée pour le processus de préparation.

Remarque : les modèles privés ou soumis à licence peuvent demander une authentification Hugging Face.
